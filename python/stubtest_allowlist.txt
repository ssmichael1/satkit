# stubtest allowlist for satkit.
#
# Entries are regexes, fullmatched against each error's OBJECT PATH. Run the
# check with the wrapper, which also registers the native submodules
# (satkit.sun, satkit.density, ...) so their own .pyi files are checked:
#
#   python python/run_stubtest.py
#
# The wrapper passes two CLI flags that switch off whole PyO3-idiom check
# categories globally (cleaner than listing every object path):
#
#   --ignore-positional-only   operator dunders are positional-only at runtime
#   --ignore-disjoint-bases    every pyclass is a PEP 800 disjoint base
#
# Every entry below is an exact object path with a reason. Real stub/runtime
# drift is fixed in the .pyi; the only drift listed here is owned by another
# open branch and says so. stubtest errors on unused entries, so an entry must
# be deleted as soon as its cause is fixed.
#
# What stubtest cannot see at all (so the doc-example tests and the unit tests
# have to): return types; parameter types (only names, kinds and defaults are
# compared); the arguments of a binding that takes bare `*args`; and anything
# about constructors (next block).

# --- PyO3 constructors ---------------------------------------------------------
# A pyclass constructor is `__new__` at runtime (the #[new] signature is the
# class __text_signature__) and runtime `__init__` takes nothing, while the stubs
# declare `__init__` so mkdocstrings and IDEs render the constructor. stubtest
# reports every stub __init__ parameter as missing and every runtime __new__
# parameter as missing from the stub, so constructors are not checked here.
# python/test/test_stub_signatures.py compares each stub __init__ with the
# runtime __text_signature__ instead, where the binding declares one.
#
# Declared runtime signature, checked by test_stub_signatures.py:
satkit\.satkit\.duration\.__init__
satkit\.satkit\.duration\.__new__
satkit\.satkit\.ecomparams\.__init__
satkit\.satkit\.ecomparams\.__new__
satkit\.satkit\.kepler\.__init__
satkit\.satkit\.kepler\.__new__
satkit\.satkit\.propsettings\.__init__
satkit\.satkit\.propsettings\.__new__
satkit\.satkit\.satproperties\.__init__
satkit\.satkit\.satproperties\.__new__
satkit\.satkit\.satstate\.__init__
satkit\.satkit\.satstate\.__new__
# Declared runtime signature `(*args, <keywords>)`; the stub spells out the
# positional forms as positional-only overloads, which stubtest cannot match
# against `*args` (test_stub_signatures.py checks the keywords).
satkit\.satkit\.itrfcoord\.__init__
satkit\.satkit\.itrfcoord\.__new__
satkit\.satkit\.time\.__init__
satkit\.satkit\.time\.__new__

# against (checked by the constructor calls in the doc examples).

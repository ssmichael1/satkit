# Keplerian Orbital Elements

Classical (osculating) Keplerian elements with two-body propagation and conversion to and from position and velocity. Distances are in meters and angles in radians; the elements are referred to whatever inertial frame the state is in (GCRF elsewhere in satkit). They are not the mean elements of a TLE. Background: [Keplerian Elements](../guide/kepler.md); tutorial: [Keplerian Elements](../tutorials/Keplerian%20Elements.ipynb).

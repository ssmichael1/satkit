# Planets

Low-precision heliocentric positions of Mercury through Pluto and the Earth-Moon barycenter, from the Keplerian-element approximations of [Standish & Williams](../guide/references.md#standish) (JPL Solar System Dynamics). The Sun and the Moon are not valid bodies.

For higher accuracy, use the [`jplephem`](jplephem.md) module which provides
full JPL ephemeris data.

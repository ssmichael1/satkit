# ITRF Coordinate

Positions in the International Terrestrial Reference Frame with conversion to and from geodetic coordinates on the WGS 84 ellipsoid ([NGA 2014](../guide/references.md#nga2014)). The Cartesian → geodetic conversion is the iterative reduced-latitude method of [Bowring (1976)](../guide/references.md#bowring1976); geodesic distances and headings use the nested-equation solution of [Vincenty (1975)](../guide/references.md#vincenty1975).
